# أثر | ATHAR Studio

موقع عربي RTL مبني باستخدام React وVite.

## التشغيل محلياً
1. ثبّت Node.js.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`.
4. نفّذ `npm run dev`.

## البناء والنشر على Vercel
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: `./`

## ملاحظات مهمة قبل الإطلاق
- الأعمال في المعرض نماذج تصورية وليست مشاريع حقيقية.
- نموذج التواصل واجهة تجريبية فقط ولا يرسل البيانات إلى خادم. يلزم ربطه بخدمة آمنة قبل استقبال طلبات العملاء.
- لا توجد لوحة إدارة أو نظام دفع في هذه النسخة.
- استخدم شعار أثر النهائي وأصول الصور والفيديو المرخصة عند توفرها.

## ملاحظات البناء
- تم تثبيت إصدارات الحزم (بدل latest) لتجنب أعطال البناء عند صدور إصدارات جديدة.
- يتطلب المشروع Node.js بإصدار 20.19 أو أحدث (Vercel يستخدم 22 افتراضياً).
- إن فشل البناء بخطأ في `src/main.jsx` فتأكد أن الملف في المستودع يطابق هذه النسخة تماماً، وأن السطر الأول هو `import React, { useState } from 'react';`.
