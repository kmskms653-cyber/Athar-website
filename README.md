# أثر — منصة ATHAR STUDIO

موقع React + Vite عربي، بهوية فاخرة هادئة، مع لوحة إدارة واستديو قوالب مدمج.

## ما تتضمنه هذه النسخة

- الموقع التعريفي وأقسام الخدمات ومعرض الأعمال.
- لوحة إدارة عبر `/#admin`، وتسجيل دخول Google للمدير الموثق فقط.
- استديو القوالب عبر `/#studio`، ويُحمّل من `public/studio/index.html` على النطاق نفسه.
- ثمانية قوالب، معاينة وتعديل النصوص والألوان والمقاسات وإضافة الصور والشعار وتصدير PNG.
- حفظ التصاميم والإعدادات في IndexedDB على الجهاز والمتصفح المستخدمين.
- نموذج تواصل يحفظ الطلبات في Firestore بدلاً من الاعتماد على فتح تطبيق البريد.
- قسم طلبات العملاء في لوحة الإدارة مع إمكانية تغيير حالة الطلب.

## التشغيل محلياً

يتطلب Node.js 20.19 أو أحدث.

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## إعداد Firebase قبل النشر

المشروع مرتبط بإعدادات Firebase الموجودة في `src/firebase.js`.

1. في Firebase Console، فعّل Authentication ثم مزود Google.
2. أضف نطاق Vercel الفعلي إلى Authentication → Settings → Authorized domains.
3. افتح Firestore Database، ثم انشر قواعد الملف `firestore.rules`.
4. تأكد أن حساب المدير هو `KMskms653@gmail.com` وأنه موثق لدى Google.
5. اختبر إرسال طلب من الموقع، ثم افتح `/#admin` وسجّل الدخول بالحساب المعتمد وتحقق من ظهور الطلب.

> لا تضع مفاتيح خدمة Firebase الإدارية أو Service Account في ملفات الواجهة. إعدادات Firebase Web الظاهرة في التطبيق ليست بديلاً عن قواعد Firestore؛ القواعد هي التي تفرض صلاحيات القراءة والكتابة.

## روابط الاستخدام بعد النشر

- الموقع: `/`
- لوحة الإدارة: `/#admin`
- استديو القوالب: `/#studio`
- صفحة الاستديو المباشرة: `/studio/index.html`

## ملاحظات تشغيل مهمة

- التصاميم المحفوظة في الاستديو محلية على الجهاز والمتصفح، ولا تتزامن بين الأجهزة أو حسابات المستخدمين في هذه النسخة.
- مكتبة تصدير PNG والخطوط في الاستديو تُحمّل من خدمات CDN وGoogle Fonts؛ يلزم اتصال إنترنت للسلوك الكامل.
- طلبات العملاء تُخزّن في Firestore. حماية قواعد Firestore تمنع الزوار من قراءتها أو تعديلها، وتسمح للمدير الموثق بذلك.
- قبل إطلاق عام واسع، يوصى بتفعيل Firebase App Check وإضافة حماية من الإرسال الآلي/الإغراق للنموذج.
- يجب اختبار تسجيل الدخول، إرسال الطلبات، تحميل الصور وتصدير PNG على نطاق Vercel الفعلي بعد نشر قواعد Firebase.

## النشر على Vercel

اربط مستودع GitHub بمشروع Vercel، واجعل Root Directory مجلد المشروع الذي يحتوي `package.json`، ثم استخدم:

- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

لا يتطلب استديو القوالب إعداد نطاق فرعي؛ فهو جزء من نفس الموقع.
